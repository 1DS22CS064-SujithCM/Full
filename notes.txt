9. ContextApi (state management tool)
- Context API allows us to share data across multiple components without manually passing props through every intermediate component (avoids prop drilling).
- It is commonly explained in 3 steps.

Step 1: create one create (like userContext, storageContext, employeeContext )
- Create a context instance using createContext().
- Create a Provider component that provides the data.
- children is a prop that represents the components placed inside the Provider.
- The data we want to share is passed using the value prop.
- children refers to all components/elements placed inside the <UserContext>...</UserContext>.

userContext.jsx: 
import React, { createContext } from 'react'

export const dataContext= createContext()

const UserContext = ({children}) => {

  const user={
    username:"something",
    age: 10,
    city: "None"
  }
  return (
    <div>
        <dataContext.Provider value={user}>
            {children}
        </dataContext.Provider>
        
      In UserContext.jsx
    </div>
  )
}

export default UserContext

2. useEffect: 
- useEffect(callback , dependencies) // here callback is what to run and dependencies is when to run
- 3 types are there:
a. useEffect without dependencies
b. useEffect with empty array
c. useEffect with variable

import React from 'react'
import { useState,useEffect } from 'react'

const UseEffectOne = () => {
    const [data,setData]=useState(0);
    const [otherdata,setOtherData]=useState(5);

    // without dependency it running when every the change happens in this component (i.e UseEffectOne )
    useEffect(()=>{
        document.title=`${data} is clicked!`
    })

    // with empty array only for one time
    useEffect(()=>{
        document.title=`${data} is clicked!`
    },[])

    // with variable 
    useEffect(()=>{
        document.title=`${otherdata} is clicked!`
    },[otherdata])

    const increaseCount=()=>{
        setData(data+1);
    }

    const decreaseCount=()=>{
        setData(data-1);
    }

  return (
    <div>
    
      <h1> Count value is : {data}</h1>
      <button onClick={increaseCount}>Click to increase</button>
      <button onClick={decreaseCount}>Click to decrease</button>

      <br></br>
      <h1>Other Count value is : {otherdata}</h1>
      <button onClick={()=>{setOtherData(otherdata+5)}}>Click to increase by 5</button>
    </div>
  )
}

export default UseEffectOne

5. UseReducer
- use to reduce complex state function
- use to reduce more number of state function

useReducer take two input arguments 
1. reducer function: the logic of what to do
2. initialState: inital value

UseReducer returns array of two elements:
1. state: current state of that thing
2. dispatch: update that state

Reducer function have two parameter:
1. state: current state that is been used
2. action: what need to be done for the current stage (what ever is passed in the dispatch function can be accessed in the action to perform various action in the reducer accordingly)

code snippet:
import React from 'react'
import { useReducer } from 'react';


const ACTION={
    INCREASE:"increase",
    DECREASE:"decrease"
}

const initialState={count:0};

const reducer =(state,action)=>{
    switch(action.type)
    {
        case ACTION.INCREASE:
            return {count:state.count+1};
        case ACTION.DECREASE:
            return {count:state.count-1};
        default:
            return state
    }
}

const UseReducer = () => {

    const [ state,dispatch]=useReducer(reducer,initialState);

    const increaseCount=()=>{
        dispatch({type:ACTION.INCREASE})
    }

    const decreaseCount=()=>{
        dispatch({type:ACTION.DECREASE})
    }
  return (
    <div>
      <h2>Count: {state.count}</h2>
      <button onClick={increaseCount}>Increase</button>
      <button onClick={decreaseCount}>Decrease</button>
    </div>
  )
}

export default UseReducer

6. UseLAyoutEffect:
- it is similar to useEffect but runs before the dom printing
- used to access the layout info like style height width details
- it is sync only execute next line when current line is done

import React, { useEffect, useLayoutEffect, useState,useRef } from 'react'

const UseLayout = () => {
  const [toggle, setToggle] = useState(false)
  const dom=useRef()

  useLayoutEffect(() => {
    if(dom.current!=null)
    {
        const dimension=dom.current.getBoundingClientRect();
        dom.current.style.paddingTop=`${dimension.height}px`
    }
  }, [toggle])

  useEffect(() => {
    if(dom.current!=null)
    {
        const dimension=dom.current.getBoundingClientRect();
        dom.current.style.paddingTop=`${dimension.height}px`
    }
  }, [toggle])
  

  return (
    <div>
      <button onClick={() => setToggle(!toggle)}>Toggle</button>
      {toggle && <h4 ref={dom}>Hello</h4>}
    </div>
  )
}

export default UseLayout 

Definition:
1. useState
Used to store and manage data that can change inside a component.
When the state changes, the component re-renders.

2 useEffect
Used to perform side effects like API calls, timers, or subscriptions.
It runs after the component renders.

3. useContext
Used to share data between components without passing props manually.
Commonly used for theme, authentication, and user data.

4. useRef
Used to store a value that persists between renders without causing re-rendering.
It can also be used to access DOM elements directly.

5. useReducer
Used to manage complex state using a reducer function and actions.
It is an alternative to useState for complex state logic.

5. useLayoutEffect
Runs after the DOM is updated but before the browser displays it.
Used when we need to measure or modify the DOM before the user sees it.

Other topics in react

1. JSX

* JSX allows us to write HTML-like code inside JavaScript.
* It makes writing UI easier and readable.
* JSX is converted into JavaScript by React.

Code snippet:

```jsx
const element = <h1>Hello World</h1>
```

2. Props

* Props are used to pass data from a parent component to a child component.
* Props are read-only and should not be directly changed by the child.

Code snippet:

```jsx
function Child(props) {
  return <h1>Hello {props.name}</h1>
}

function App() {
  return <Child name="Sujith" />
}
```

3. State vs Props

* State is data managed inside a component and can be changed using a state function.
* Props are data passed from a parent component to a child component.

Simple difference:

```text
State → managed by the component
Props → received from parent
```

4. Conditional Rendering

* Conditional rendering means displaying different UI based on a condition.
* We can use `if`, ternary operator, or `&&`.

Code snippet:

```jsx
{isLoggedIn ? <h1>Welcome</h1> : <h1>Please Login</h1>}
```

5. Lists and Keys

* `map()` is used to display multiple elements from an array.
* `key` helps React identify which list item has changed.

Code snippet:

```jsx
const users = ["A", "B", "C"]

{users.map((user, index) => (
  <h1 key={index}>{user}</h1>
))}
```

6. Components

* Components are reusable parts of the UI.
* A component can contain HTML-like JSX, JavaScript logic, state and events.

Example:

```jsx
function Header() {
  return <h1>My Website</h1>
}
```

7. Forms

* React forms are commonly handled using state.
* The input value is stored in state and updated using `onChange`.

Code snippet:

```jsx
const [name, setName] = useState("")

<input
  value={name}
  onChange={(e) => setName(e.target.value)}
/>
```

This is also related to the **two-way binding** already present in your PDF. 

8. Component Lifecycle

A component generally goes through three stages:

1. Mounting → component is created and displayed.
2. Updating → component changes because of state or props.
3. Unmounting → component is removed.

`useEffect` can be used to perform actions related to these stages.

9. useMemo

* `useMemo` is used to remember a calculated value.
* It can avoid unnecessary calculations when a component re-renders.

Basic syntax:

```jsx
const result = useMemo(() => {
  return expensiveCalculation(data)
}, [data])
```

10. useCallback

* `useCallback` is used to remember a function between renders.
* It can help avoid unnecessary function creation during re-rendering.

Basic syntax:

```jsx
const handleClick = useCallback(() => {
  console.log("Clicked")
}, [])
```

11. Virtual DOM

* Virtual DOM is a lightweight representation of the actual DOM.
* When state changes, React compares the changes and updates the required parts of the actual DOM.

12. React Re-rendering

* When state or props change, the component can re-render.
* Re-rendering means React runs the component again and updates the UI where required.
